# 공조냉동기계기술사 서브노트 목차

엑셀 목차의 첫 번째 시트를 모바일에서도 편하게 볼 수 있도록 만든 정적 웹페이지입니다. 두 번째 시트의 내용은 포함하지 않았습니다.

## 기능

- 대분류와 중분류를 접고 펼쳐 목차를 탐색할 수 있습니다.
- 제목, 학습 키워드, 기출 회차와 문제 내용을 검색할 수 있습니다.
- 목차 항목을 열면 학습 키워드와 기출 문제를 확인할 수 있습니다.
- 각 기출 문제에 회차와 문제 번호를 표시하고, 배점은 문제 끝에 표시합니다.
- 별도의 서버나 라이브러리 없이 `index.html` 하나로 실행됩니다.

## GitHub Pages에 게시하기

1. `index.html`을 GitHub 저장소의 최상위 폴더에 올립니다.
2. 저장소의 **Settings → Pages**에서 게시 소스를 설정합니다.
3. 브랜치 배포를 선택하고 `main` 브랜치의 `/ (root)` 폴더를 지정한 뒤 저장합니다.
4. 게시가 완료되면 GitHub Pages가 안내하는 주소로 접속합니다.

저장소가 공개 상태라면 페이지의 목차와 기출 문제도 누구나 볼 수 있습니다. 비공개 자료라면 저장소 공개 범위와 Pages 이용 조건을 먼저 확인하세요.

## 파일 구성

```text
.
├── index.html   # 웹페이지와 목차 데이터
└── README.md    # 프로젝트 안내
```
